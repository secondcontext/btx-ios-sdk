# Developer guides

Start with the [iOS quickstart](quickstart.md), then add the features your app needs.

## Core features

- [Customer Messenger](customer-messenger.md): in-app support threads and replies.
- [Help Center](help-center.md): searchable help articles inside your app.
- [Rage-shake feedback](feedback.md): issue reports with customer-reviewed screenshots.
- [Telemetry](telemetry.md): customer-linked events and diagnostic context.
- [Feature flags](feature-flags.md): customer-targeted feature controls.

## Hardware diagnostics

Use [hardware telemetry](device-telemetry.md) to connect device state with diagnostic events.

- [Device health](device-health.md): battery, charging, firmware, and custom readings.
- [Connection diagnostics](connection-diagnostics.md): failure stages, retries, and readiness.
- [Firmware update diagnostics](firmware-update-diagnostics.md): update failures and verified versions.

## Integration

- [macOS](macos.md): use BTX in a SwiftUI or AppKit Mac app.
- [Push notifications](push-notifications.md): receive operator replies through APNs.
- [Theming](theming.md): match the SDK to your app.
